# Tic Tac Toe — Alternating Symbols

A front-end-only React and Vite game. You play against the computer, and your symbol alternates every time a new game starts:

- Game 1: You are X, computer is O
- Game 2: You are O, computer is X
- The pattern continues for all subsequent games.

No backend or middleware is used.

## Run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
